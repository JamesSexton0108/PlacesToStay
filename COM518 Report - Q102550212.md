1\. The first requirement is to allow users to retrieve all
accommodation options in a given location. In order to do this, a GET
HTTP request method should be used, as we are just reading from the
database, not altering it. We can treat accommodation as a resource and
location as a filter in the URL, creating a route that looks like:

/accommodation/location/:location

This structure means that the desired location can be specified
dynamically through the URL. Using express, this can be implemented with
app.get(), with the location parameter being accessed using
req.params.location. The relevant data can then be accessed using an SQL
query in the form "SELECT \* FROM accommodation WHERE location = ?
COLLATE NOCASE". This query is then returned in the JSON format, which
can then be parsed into a more easily readable format in later tasks.

2\. The second requirement follows largely the same structure as the
first, utilizing app.get() with multiple parameters in order to filter
accommodation in a given location by type. Another SQL query is also
used to achieve this, coming in the form "SELECT \* FROM accommodation
WHERE type = ? AND location = ? COLLATE NOCASE".

3\. The third requirement will need to include an app.post() request as
we are inserting data into the database. We will use a separate insert
statement and update statement, with the insert adding new entries into
the bookings table and the update updating the dates table to reflect
the new availability based on the number of people being inserted into
the new booking. The insert will look something like "INSERT INTO
acc_bookings(accID, thedate, userID, npeople) VALUES(?,?,?,?)" and the
update will look like "UPDATE acc_dates SET availability =
availability - ? WHERE accID = ? AND thedate = ?".
