1\. The first requirement is to allow users to retrieve all
accommodation options in a given location. In order to do this, a GET
HTTP request method should be used, as we are just reading from the
database, not altering it. We can treat accommodation as a resource and
location as a filter in the URL, creating a route that looks like:

/accommodation/location/:location

This structure means that the desired location can be specified
dynamically through the URL. Using express, this can be implemented with
app.get(), with the location parameter being accessed using
req.params.location. The relevant data can then be accessed using an SQL
query in the form "SELECT \* FROM accommodation WHERE location = ?
COLLATE NOCASE". This query is then returned in the JSON format, which
can then be parsed into a more easily readable format in later tasks.
